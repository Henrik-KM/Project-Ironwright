# Concept Art

These images show the intended emotional contrast from early to late game.

## Files

- `early-game.png` — damaged Heartforge, one robot, limited light, immediate organic danger.
- `mid-game.png` — compact self-maintaining base, routine machine activity, continuing outside pressure.
- `late-game.png` — dense autonomous machine defence and expeditions around the same constrained home.
- `progression-board.png` — full-resolution combined progression image.
- `progression-board-web.png` — reduced version used by the repository README.

## Canonical interpretation

The images are mood references, not literal feature specifications.

- UI labels and numbers are illustrative.
- No hostile robot faction is intended.
- The base should remain spatially constrained even in late game.
- Late-game scale comes from robot count, intelligence, and coordinated activity.
- The early game must remain darker, smaller, and more frightening than any conventional base-builder opening.
- Do not derive production-ready 3D assets by treating the images as exact orthographic designs.
