# Changelog

- Rebuilt the product around long-form survival strategy rather than RTS expansion.

- Added early/mid/late concept-art progression references.
- Added machine-readable design contracts and a minimal Godot project shell.
- Added Codex instructions, first implementation task, validation tooling, and GitHub workflow.
