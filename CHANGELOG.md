# Changelog

## 0.2.0 — 2026-08-19

- Restored the complete browser launch surface: `web/index.html`, `web/styles.css`, and every source part referenced by the game and simulation manifests.
- Added a full playable First Light implementation rather than placeholder files.
- Changed the Mechromancer to automatically target and shoot the nearest organic enemy within range.
- Added a visible automatic target lock and removed manual click-to-fire from the controls.
- Added the persistent urban world, compact Heartforge, organic ecology, physical North Ruins expedition, live command map, explainable robot autonomy, save/load, defeat, and victory states.
- Added deterministic simulation tests, including automatic-fire range tests and a complete physical expedition round trip.
- Added a browser-file smoke test so missing launch or segmented-source files fail validation.

## 0.1.0 — 2026-08-18

- Added the initial playable-slice documentation, source loader, manifests, and validation scaffold.

## 0.0.0 — 2026-08-18

- Rebuilt the product around long-form survival strategy rather than RTS expansion.
- Locked one constrained Heartforge, one ordinary resource, organic enemies, and no scheduled-wave main loop.
- Defined autonomy as permanent removal of player work.
- Added the revised GDD, ecology, sandbox, art, architecture, roadmap, and playtest documents.
