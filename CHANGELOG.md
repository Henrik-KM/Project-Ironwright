# Changelog

## 1.1.0 — 2026-08-18

- Added the first fully playable browser vertical slice.
- Implemented direct movement, combat, contextual interaction, victory, defeat, pause, autosave, and load.
- Added one persistent urban world in which remote robots and organic organisms remain physical entities.
- Added autonomous salvage, perimeter defence, role creation, retreat, convoy cohesion, and machine decision explanations.
- Added a physical North Ruins expedition that can be followed in-world or viewed on a live command map.
- Added a causal Cognition Core / Cathedral Beast endgame rather than a scheduled wave.
- Added deterministic simulation tests, browser smoke screenshots, Node validation, and CI coverage.
- Renamed the project consistently from Project Ironwight to Project Ironwright.

## 1.0.0 — 2026-08-18

- Rebuilt the product around long-form survival strategy rather than RTS expansion.
- Locked one constrained Heartforge, one ordinary resource, organic enemies, and no scheduled-wave main loop.
- Defined autonomy as permanent removal of player work.
- Added complete revised GDD, ecology, sandbox, art, architecture, roadmap, and playtest documents.
- Added early/mid/late concept-art progression references.
- Added machine-readable design contracts and a minimal Godot project shell.
- Added Codex instructions, first implementation task, validation tooling, and GitHub workflow.
