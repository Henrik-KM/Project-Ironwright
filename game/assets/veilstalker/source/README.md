# Veilstalker production asset

`veilstalker.gltf` is an original, dependency-free high-definition organic
predator shell generated by `build_veilstalker_asset.py`. It uses the shared
mesh-buffer helpers only to keep the source deterministic and reviewable.

The asset supplies the layered thorax, protected threat eyes, sensory cowl
spines, articulated mandibles, veil membranes, tendrils, hooks and threat eyes.
Runtime movement, attack wind-up, ecology, collision and damage remain owned by
`OrganicEnemy3D`.
