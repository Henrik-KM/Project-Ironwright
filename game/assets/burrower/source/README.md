# Burrower authored asset

This is an original, dependency-free glTF shell for the drill-bearing
territorial family. The layered body, concentric drill rings, bore lamps,
jaw hooks and side fins make its subterranean role readable before contact.

The drill head now carries a restrained four-tooth cutting crown in front of
the concentric rings, giving the bore tool a readable working edge at close
camera distance without changing its stable drill socket. The builder is
reproducible and has no external runtime asset dependency.
Patrol, terrain contact, attack timing and ecology remain owned by
`OrganicEnemy3D`; the shell supplies presentation and stable socket names.
The layered structural plates and bone accents are brighter than the wet
shell/flesh base to keep the drill-bearing silhouette readable in a group.
