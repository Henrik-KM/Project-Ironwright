# Root Cistern landmark asset

`root_cistern.gltf` is an original generated production placeholder for the
late-game Root Cistern landmark. It uses layered root-organ masses, signal
pylons, crown ribs and tethered pulse cables to give the endgame region a
distinct silhouette at tactical distance.

The shell is presentation-only. Region pressure, endgame protocols, discovery,
LOD and persistence remain owned by the existing region and endgame services.
