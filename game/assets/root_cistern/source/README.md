# Root Cistern landmark asset

`root_cistern.gltf` is an original generated authored shell for the late-game
Root Cistern landmark. It uses layered root-organ masses, an overlapping
segmented mantle, signal pylons, crown ribs, basin inlays, signal sockets and
tethered pulse cables to give the endgame region a distinct silhouette and
readable surface hierarchy at tactical distance.

The shell is presentation-only. Region pressure, endgame protocols, discovery,
LOD and persistence remain owned by the existing region and endgame services.
