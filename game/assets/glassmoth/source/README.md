# Glassmoth authored asset

This is an original, dependency-free glTF shell for the luminous territorial
swarm family. Swept wing membranes, parented vascular veins, pale spars,
antennae and luminous oculi give the airborne silhouette a readable living
construction at tactical-camera distance.

The wing vein lattice follows the existing imported wing animation. Movement,
territory, noise response, targeting and attack timing remain owned by the
runtime organic actor; the shell supplies presentation and stable socket names.
