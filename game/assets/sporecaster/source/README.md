# Sporecaster authored asset

This is an original, dependency-free glTF shell for the ranged infestation
family. Its layered gill fan, five suspended spore sacs and paired sensory
oculi make the species readable as a distance-keeping ecological threat from
the tactical camera.
Its shell, membrane and bone accents deliberately separate from the wet flesh
base, keeping the suspended sacs and gill fan readable at compact distance.

The builder is reproducible and has no external runtime asset dependency.
Gameplay targeting, noise, impairment, ecology and attack timing remain owned
by `OrganicEnemy3D`; the shell provides presentation and stable socket names.
