# Autonomous outpost authored shelter source

`build_outpost_asset.py` generates the original high-definition outpost shelter
shell from the shared project mesh builder. It provides the fixed foundation,
shelter, roof, service vent, service panel, status beacon and production marker.

Role signatures, tier frames, damage memory, repair, hauling and autonomous
operation remain owned by `Outpost3D`; the imported asset is presentation-only.
No third-party runtime asset is used.
