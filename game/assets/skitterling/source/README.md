# Skitterling authored asset

This is an original, dependency-free glTF shell for the small scavenger
family. Layered carapace ridges, paired antennae, mandibles, sensory fins and
many articulated legs give the common organism a readable close-range role.
The shell ridges and bone accents are intentionally brighter than the wet
carapace base so the small body remains legible at tactical-camera distance.

The builder is reproducible and has no external runtime asset dependency.
Noise attraction, feeding, fleeing, attack timing and ecology remain owned by
`OrganicEnemy3D`; the shell supplies presentation and stable socket names.
