# Broodmass authored asset

This is an original, dependency-free glTF shell for the large nest-organism
family. Layered brood plates, paired lobes, a forward maw, crown spines,
membrane fins and hooked legs give the threat a broad encounter-space
silhouette at the tactical camera distance.

The builder is reproducible and has no external runtime asset dependency.
Nest pressure, health, movement, attacks and ecology remain owned by
`OrganicEnemy3D`; this shell supplies presentation and stable socket names.
