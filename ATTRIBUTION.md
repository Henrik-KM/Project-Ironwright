# Asset Attribution and Provenance

No third-party runtime art, audio, or code assets are included in the initial repository scaffold.

The images under `docs/concept-art/` were generated for Project Ironwight as design references. They are not production-ready runtime assets.

Before committing an external asset, add an entry with the following fields and preserve the original licence file where redistribution is permitted.

| Asset ID | Asset or pack | Creator/source | Official URL | Licence | Date obtained | Local licence file | Modifications | Redistribution notes |
|---|---|---|---|---|---|---|---|---|
| _Example_ | _Pack name_ | _Creator_ | _Official source_ | _Exact licence_ | _YYYY-MM-DD_ | `game/assets/third_party/.../LICENSE.txt` | _What changed_ | _Any restrictions_ |

Do not record a licence from a third-party mirror when an official source exists. Recheck the official licence at acquisition time.
